# Security Policy

This repository holds the source of the bitcoin.org website.

## Bitcoin Core

Vulnerabilities in Bitcoin Core must not be reported here. Follow the
[Bitcoin Core security policy](https://bitcoincore.org/en/security-advisories/)
and email security@bitcoincore.org.

## The bitcoin.org website

To report a security problem with the website itself, for example a script,
page or link that could be abused to harm visitors, use the **Report a
vulnerability** button in the [Security tab](https://github.com/bitcoin-dot-org/Bitcoin.org/security)
of this repository. Please do not open a public issue for it.

## Listed wallets and exchanges

If a wallet or exchange listed on bitcoin.org has been compromised, or a
listing points to a malicious site, open an issue so the listing can be
reviewed quickly. Include a link to the evidence, such as an announcement
from the project.
